## Состав системы

- **Go-API** — Go 1.26, 27 модулей в `internal/` (перечень и назначение каждого —
  [`ARCHITECTURE.md`](ARCHITECTURE.md) §4.2, сверяется машиной).
- **PostgreSQL 16** — 66 миграций (`0001`…`0066_notifications`). Таблицы — [`SCHEMA.md`](SCHEMA.md).
- **web/app** — кабинет: React + TanStack + Tailwind v4 + shadcn/ui; графики аналитики —
  recharts за ленивой загрузкой, в общий чанк не входят.
- **web/renderer** — preact/compat + zod, **бюджет 60 КиБ gzip** (сейчас **47.15**, числа
  `check:bundle`, гейт CI). Свои пороги рядом: `embed/v1.js` 4 (3.88), `dist/print/` 60
  (38.64), `dist/slots/` 12 (1.88), `dist/cancel/` 8 (1.16), шрифты формы 400 (326).
- **e2e** — девять Playwright-сценариев против prod-local: `full-loop`, `builder-keyboard`,
  `form-settings`, `visits-funnel`, `workspace-team`, `multipage`, `embed`, `logic`, `design`.
- **Эксплуатация** — бэкапы БД в Yandex (`deploy/backup.sh` в cron, восстановление —
  `deploy/RESTORE.md`), мониторинг UptimeRobot, ротация docker-логов.

**Пространства:** у аккаунта личное плюс командные; владелец ровно один и он же плательщик —
**подписка принадлежит аккаунту**. Права спрашиваются по действию (`Can`), а не по роли.
Подробности — [`WORKSPACES.md`](WORKSPACES.md).

**Схема формы** — JSONB, модель v4 при `schemaVersion: 1` (номер заморожен до релиза,
[`EDITOR.md`](EDITOR.md) §8): вопрос = группа блоков, текст — плоские спаны, заголовок формы —
блок документа, бит ряда на первом блоке группы; разрыв страницы, логика и оформление —
необязательные поля, версию не поднимают. Контракт API — [`API.md`](API.md).

**Живые колонки формы рядом со схемой** (то, что обязано меняться без перепубликации): пароль,
бейдж, письмо респонденту, расписание записи. Схема замерзает при публикации — ссылке на
расписание там не место.

**У доставки ответа наружу один механизм на оба вида цели:** своя очередь у каждой
(`sheet_queue`, `webhook_queue`), расписание у ЦЕЛИ, постановка — тем же SQL-утверждением, что
вставка ответа. `outbox` остался транспортом ПИСЕМ. Различаются виды только пачкой: у Таблиц
это один `values.append` на 200 строк, у вебхука — 200 запросов подряд, поэтому доставщик у
каждого свой. [`INTEGRATIONS.md`](INTEGRATIONS.md) §5–§7 и §13.

## За владельцем

**Тег на прод не поставлен.** Он выкатит двадцать восемь работ разом (список выше) и **все
миграции от `0035` до `0066`** — счёт по `git diff v0.26.2..main -- migrations/` (31 файл), а не по
перечисленным работам: в `main` с 25 августа влиты 53 PR. ⚠ Среди них `0065` **удаляет
неотправленные события канала `gsheets` из `outbox`** вместо того, чтобы переводить их в новую
очередь: боевыми данными на сегодня не дорожим (решение владельца 2026-09-12). Если к моменту
выкатки это перестанет быть верным — перевод писать до тега. Вместе с ними уедут **закрытые на
бесплатных планах гейты** — см. ниже. ⚠ Среди миграций `0054` **необратимо правит снапшоты**:
формы, набранные системным шрифтом, поедут на Inter.

**Гейты, закрытые данными, а не кодом.** После наката недоступны никому, включая владельца,
пока аккаунт на `legacy_free`: `submissions_partial` (сбор незавершённых, `0041`),
`form_respondent_email` (письмо респонденту, `0046` — здесь это замысел: платной является
сама отправка). Открыты всем и ждут решения: `analytics_sources`, `analytics_funnel`,
`form_link_preview`, `booking_schedules_max`. Включение любого — один `UPDATE` без выкатки
([`BILLING.md`](BILLING.md) §6).

**Ввод интеграции Google в строй (на проде не работала ни разу):** три API в Google Cloud,
прод-клиент OAuth, ключ Picker'а, `GOOGLE_OAUTH_*` и `GOOGLE_PICKER_API_KEY` в серверном
`.env`. ⚠ **Пока приложение в статусе Testing, refresh-токены живут 7 дней** — интеграция
будет умирать у всех раз в неделю, что бы ни делал наш код; открытый вопрос — классификация
scope `drive.file` в Data access. **Вебхукам ничего из этого не нужно:** провайдера у них нет.

**Уже на проде и требует внимания:**

- **Бейдж «Сделано в Trillix»** на каждой форме ведёт на апекс `trillix.ru`, который Caddy не
  обслуживает — респондент попадает на чужую заглушку.
- **Выкатка не подтверждается сама:** успех джоба означает «ssh вернул 0»

- **Файлы в ответах** ждут инфраструктуры: CORS на бакете reg.ru, `S3_PUBLIC_ENDPOINT`, шаг

**Глазами не смотрели:** фазы 14, 15, 17, частично 18, 19–21, шторку «Оформление», файлы в

(участники, откат черновика, страница расписания). По фазе 25

**Ротация `FORM_TOKEN_SECRET` гасит разом:** токены разблокировки форм под паролем, токены
