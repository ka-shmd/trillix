## Состав системы

- **Go-API** — Go 1.26, 28 модулей в `internal/` (перечень и назначение каждого —
  [`ARCHITECTURE.md`](ARCHITECTURE.md) §4.2, сверяется машиной).
- **PostgreSQL 16** — 73 миграции (`0001`…`0073_signup_profile_drop_full_name`). Таблицы — [`SCHEMA.md`](SCHEMA.md).
- **web/app** — кабинет: React + TanStack + Tailwind v4 + shadcn/ui; графики аналитики —
  recharts за ленивой загрузкой, в общий чанк не входят.
- **web/renderer** — preact/compat + zod, **бюджет 60 КиБ gzip** (сейчас **47.94**, числа
  `check:bundle` на ветке согласия, гейт CI). Свои пороги рядом: `embed/v1.js` 5 (4.00), `dist/print/` 60
  (41.19), `dist/slots/` 12 (2.89), `dist/cancel/` 8 (1.16), `dist/document/` 8 (0.82), шрифты формы 400 (326).
- **e2e** — десять Playwright-сценариев против prod-local: `full-loop`, `builder-keyboard`,
  `form-settings`, `visits-funnel`, `workspace-team`, `multipage`, `embed`, `logic`, `design`,
  `metrika`.
- **Эксплуатация** — бэкапы БД в Yandex (`deploy/backup.sh` в cron, восстановление —
  `deploy/RESTORE.md`), мониторинг UptimeRobot, ротация docker-логов.

**Пространства:** у аккаунта личное плюс командные; владелец ровно один и он же плательщик —
**подписка принадлежит аккаунту**. Права спрашиваются по действию (`Can`), а не по роли.
Подробности — [`WORKSPACES.md`](WORKSPACES.md).

**Схема формы** — JSONB, модель v4 при `schemaVersion: 1` (номер заморожен до релиза,
[`EDITOR.md`](EDITOR.md) §8): вопрос = группа блоков, текст — плоские спаны, заголовок формы —
блок документа, бит ряда на первом блоке группы; разрыв страницы, логика и оформление —
необязательные поля, версию не поднимают. Контракт API — [`API.md`](API.md).

**Живые колонки формы рядом со схемой** (то, что обязано меняться без перепубликации): пароль,
бейдж, письмо респонденту, расписание записи. Схема замерзает при публикации — ссылке на
расписание там не место.

**У доставки ответа наружу один механизм на оба вида цели:** своя очередь у каждой
(`sheet_queue`, `webhook_queue`), расписание у ЦЕЛИ, постановка — тем же SQL-утверждением, что
вставка ответа. `outbox` остался транспортом ПИСЕМ. Различаются виды только пачкой: у Таблиц
это один `values.append` на 200 строк, у вебхука — 200 запросов подряд, поэтому доставщик у
каждого свой. [`INTEGRATIONS.md`](INTEGRATIONS.md) §5–§7 и §13.

  (`docker compose -p trierra-prod-local down`) и seed-аккаунты `logic-*`, `design-*`,

## Что решено НЕ делать сейчас

Перенесено в POST-MVP: шаблоны форм, QR, Telegram. Границы закрытых фаз — в их спеках
([`design/README.md`](design/README.md)): у записи на время нет переноса брони, напоминаний и
синхронизации с внешним календарём; у вебхуков — отправки накопленных при подключении, выбора
видов событий и публичной страницы документации формата; у Метрики — параметра формы в цели
(две формы на одном счётчике в отчёте целей не разделить, пункт в `BACKLOG.md`) и гейта тарифа на
списке счётчиков аккаунта.

Сознательно не существует: мультивыделение и копипаст блоков, тач-билдер; богатый текст в
вариантах; гейт публикации незаполненной формы; частичные ответы «продолжить позже» и режим
«один вопрос — одна страница». В очереди ([`BACKLOG.md`](BACKLOG.md)): **первым — разговор с юристом
по памятке 152-ФЗ** ([`design/legal-152fz.md`](design/legal-152fz.md)), переливной клапан уведомлений,
письмо автору о поломке интеграции (на оба вида цели), перезалив листа спокойной связки,
отключение аккаунта Google.
