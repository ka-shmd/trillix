# Архив спек закрытых фаз

**Здесь лежит «почему так было решено», а не «как устроено сейчас».** Каждый файл — спека
одной закрытой работы, зафиксированная на момент согласования с владельцем и **с тех пор
не обновляемая**. Ценность архива в одном: он хранит отвергнутые альтернативы и причины
выбора, которых нет ни в коде, ни в живых справочниках.

**Правило чтения — единственное и важное:**

> При любом расхождении спеки с живым справочником **побеждает живой справочник**.
> Спека не описывает сегодняшний продукт и не является планом работ.

Не планируй работу по этим текстам. Часть разделов описывает варианты, которые **не были
приняты** или были **отменены** позже — это отмечено в шапке каждого файла.
