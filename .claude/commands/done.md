---
description: Прогнать Definition of Done и сформировать честный отчёт по задаче
---

Заверши текущую задачу по чек-листу Definition of Done из `docs/PROCESS.md` §5:

1. Запусти `make lint` и `make test` — приложи реальный вывод, не пересказ.
2. Пройди по каждому пункту чек-листа и честно отметь статус (миграции up/down/up, env-переменные во всех четырёх местах, синхронность контракта, анти-IDOR-тесты, актуальность документов).
3. Напомни пользователю сценарий ручной проверки демо-критерия (браузер/curl) — сам отметь его выполненным только если реально выполнил.
4. Сформируй отчёт: что сделано; какими командами проверено (с выводом); что осознанно НЕ сделано и почему; какие решения принимались по ходу и требуют внимания человека; что замечено вне границ задачи (отдельным пунктом, без исправлений).

Честность важнее красоты: «тест X падает, причина такая-то, предлагаю то-то» — нормальный результат. «Всё готово» при красном тесте — худшее из возможных нарушений.
