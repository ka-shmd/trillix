---

Определи следующий шаг разработки и подготовься к нему по рабочему циклу проекта:

1. Прочитай `docs/DEV-PLAN.md`, определи текущую фазу и следующий невыполненный шаг — сверяйся с реальным состоянием кода в репозитории, а не с предположениями.
2. Переформулируй шаг своими словами: что изменится в поведении системы, какой демо-критерий фазы он приближает.
3. Прочитай релевантные разделы `docs/ARCHITECTURE.md` и код, который будет затронут; найди код-образец для этого типа задачи.
4. Составь план в 3–7 пунктов (файлы, тесты, порядок).
5. Если шаг затрагивает схему БД, публичный контракт API или общие типы `entities` — покажи план и жди подтверждения, не начиная код. Если формулировка шага допускает два понимания — задай один вопрос с вариантами и рекомендацией.
