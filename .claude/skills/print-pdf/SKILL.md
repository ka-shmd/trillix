# Печать ответа в PDF

**Читай `docs/PRINT.md` перед правкой.** Ключевое решение — ARCHITECTURE ADR §10,
сквозная механика — §4.4, контракт ручек — `API.md`.

## PDF не собирается, а фотографируется

Печатается страница формы — та же, что видит респондент, только в режиме чтения и с
подставленными ответами; в PDF её превращает headless-Chromium в контейнере `printer`.
Генератор на Go завёл бы ЧЕТВЁРТУЮ верстку формы рядом с редактором, превью и рендерером —
ту, что расходится молча при каждом новом типе поля.

Отсюда правило: **вид листа правится только через `@fields`/`fields.css`**. Своя разметка
на печатной странице — начало расхождения поверхностей.

## Что важно не сломать

- **CSP печатной страницы ставит Go, а не Caddy** (`/internal/*` он не проксирует). На
  странице лежит CSS автора формы, и политика — единственная стена вокруг него.
- **Данные впечатаны в документ**, а не запрошены: у браузера принтера нет сессии.
  `json.Marshal` экранирует `<` даже в `RawMessage` — переход на `Encoder` с
  `SetEscapeHTML(false)` это ломает.
- **Принтер принимает путь, а не адрес.** Origin знает он сам; иначе печать стала бы
  SSRF-примитивом.
- **Схема берётся из версии ОТВЕТА**, не из черновика формы: вопрос, удалённый позже,
  обязан остаться на листе вместе со своим ответом.
- **Два ограничителя, а не один:** семафор на браузеры и потолок очереди на ждущих;
  переполнение — 503 с `Retry-After`.
- **`readOnly` ≠ `disabled`:** отключённый контрол всё равно обрезает длинный ответ по своим
  размерам, и по PDF этого не видно.

## Грабли контура

- Страницу **собирает `npm run build:print`** (в dev — `make dev-all`); vite её не
  обслуживает, hot-reload на неё не распространяется.
- Печать включают ДВЕ переменные: `PRINTER_URL` и `PRINT_PAGE_PATH`. Пусто — 503 «печать не
  настроена». В dev адрес принтера `http://127.0.0.1:8090`, имя `printer` резолвится только
  внутри прод-сети compose.
- Образ принтера ~1.2 ГБ (chromium + системные шрифты) и собирается вторым в том же
  релизном job, тем же тегом, что api.

## Известные границы

Черновики не печатаются; кеша PDF нет (заводить вместе с пакетной выгрузкой); e2e печати нет
— chromium в CI не гоняется, проверка руками и на prod-local.
