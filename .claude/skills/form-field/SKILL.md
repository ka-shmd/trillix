# Тип поля: сквозной срез

**Читай `web/shared/fields/README.md` перед правкой.** Здесь — точки, которые забывают.

## Тип блока описан тремя файлами — по одному на слой (фаза 16)

Одинаковые имена, слои не импортируют друг друга поперёк:

| Слой | Файл |
|---|---|
| контракт | `web/shared/entities/blocks/<type>.ts` |
| вид у респондента | `web/shared/fields/kinds/<type>.tsx` |
| редактор | `web/app/src/features/forms/builder/kinds/<type>.tsx` |

У каждого слоя **исчерпывающий `Record<BlockType, …>` без `Partial` и без дефолтов**: тип без
файла или без поля **не компилируется**. Прежних семи наборов-предикатов
(`CHOICE_TYPES`/`PLACEHOLDER_TYPES`/…) больше нет — предикаты **выводятся** из реестра, и
забыть тип в наборе стало нечем.

## Новый тип проходит весь срез, иначе он полуготов

1. **Значение** — в `BLOCK_TYPES` (`web/shared/entities/blocks/contract.ts`): отсюда `z.enum`,
   порядок меню и тесты паритета.
2. **Контракт** — файл типа в `blocks/` + **Go** (`internal/domain/schema.go`: константа, тип
   в списке `blockTypes`, предикаты), синхронно, **в одном PR, с тестами обеих сторон**. Go
   реестр импортировать не может, поэтому стороны сверяет
   `TestBlockKindsParityWithFrontend` — он читает файлы реестра и падает на расхождении.
3. **Семья и кардинальность объявляются, а не перечисляются**: `family` (`answer`/`caption`/
   `content`) и `choice` (`single`/`multi`) в файле типа. Из них выводятся `isChoiceType`,
   `isSingleChoiceType`, `isContentType`, `carriesText`. Прежняя грабля («ветка, забывшая тип,
   не падает, а трактует его как соседний») закрыта обязательностью полей, но в Go то же
   ветвление остаётся ручным.
4. **Серверная валидация ответа** — `ValidateAnswers` против схемы **той версии**, по которой
   ответ отправлен.
5. **Контрол** — файл в `@fields/kinds/` + запись в реестре (`null` у неотвечаемого типа —
   объявленный факт). Похож на существующий → надевай общий `TextInput`/`ChoiceList`, не
   копируй JSX. **Проверить бюджет:** `cd web/renderer && npm run build && npm run check:bundle`
   (потолок 60 КиБ gzip).
6. **Редактор** — файл в `builder/kinds/`: разделы меню, подпись, описание, дефолты,
   поверхность строки (`text`/`placeholder`/`choice`/`object`). Меню и дефолты производные —
   отдельных списков для них больше нет.
7. **Глиф типа** — строка в `web/app/src/shared/blockIcons.ts`, ОДИН словарь на весь
   кабинет (полотно, меню, условная логика, шапка колонки в таблице ответов). Не в файле
   типа: глиф спрашивают две разные фичи, а импорт фичи из фичи запрещён. Словарь
   исчерпывающий, глифы обязаны быть разными — сторож `shared/blockIcons.test.ts`.
8. **Ячейка CSV** и **сводка** — через `domain.QuestionOrder`, общую точку для CSV, сводки и воронки.

**Что сторожит машина:** паритет с Go (`internal/domain/blockkinds_parity_test.go`), покрытие
реестра контролов (`web/app/src/entities/fieldControls.test.ts`), сходимость реестра редактора
с контрактом (`builder/kinds/registry.test.ts`). `tsc` даёт только полноту реестров — смысл
полей проверяют эти три теста.

## Кодировка ответа — строкой, всегда

Тип `Answer` — `string | string[]`, и расширять его не надо: число, дата, шкала и согласие
хранятся строками. У согласия это несущая деталь, а не экономия: булев `false` не равен `''`,
не попал бы в `isEmpty` рендерера, и обязательность молча перестала бы работать.

## Вид — в одном месте на три поверхности

`web/shared/fields/fields.css` (правила `rf-*` + токены `--rf-*`) надевают редактор, превью
билдера и рендерер. Источник истины вида — форма в режиме редактирования.

**Tailwind и shadcn в `@fields` запрещены** — они уедут в рендерер и убьют его бюджет.
Это единственная зона, где кастомный CSS законен; весь остальной кабинет — только shadcn.
